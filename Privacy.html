Notre engagement

Edu Ezziymy est une application éducative destinée à accompagner les élèves dans leur apprentissage, leur entraînement et leur suivi pédagogique.

Nous accordons une importance particulière à la protection des données personnelles et des informations scolaires des élèves.

Principe essentiel :

Edu Ezziymy ne transmet pas automatiquement les rapports des élèves à l'enseignant ou à un autre destinataire.

L'élève choisit lui-même de générer un rapport, d'utiliser la fonction Partager (Share), puis de sélectionner l'application de son choix, notamment WhatsApp ou Email.

1. Responsable de l'application

L'application Edu Ezziymy est une application éducative destinée à fournir des ressources, exercices, évaluations et outils de suivi pédagogique.

Pour toute question concernant la protection des données, veuillez utiliser les coordonnées indiquées dans la section Contact.

```
```

2. Données pouvant être traitées

Selon les fonctionnalités utilisées, l'application peut traiter certaines informations nécessaires à son fonctionnement et aux activités pédagogiques.

Catégorie Exemples Finalité
Données de l'élève Nom, prénom, classe Identification pédagogique
Résultats scolaires Notes, scores, moyennes Suivi et analyse pédagogique
Progression Exercices, activités, progression Suivi de l'apprentissage
Données techniques Informations relatives à l'appareil Fonctionnement de l'application
Données publicitaires Identifiants publicitaires et données techniques Affichage des annonces

```

3. Données scolaires des élèves

Certaines fonctionnalités permettent à l'élève d'utiliser l'application dans le cadre de son apprentissage et de générer des rapports pédagogiques.

Ces rapports peuvent contenir, selon les fonctionnalités utilisées :

  • nom ou prénom de l'élève ;
  • niveau scolaire ;
  • classe ou groupe ;
  • résultats des exercices ;
  • notes et moyennes ;
  • scores obtenus ;
  • progression pédagogique ;
  • réponses aux activités ;
  • informations nécessaires à l'analyse pédagogique.
Utilisation limitée :

Les données scolaires sont utilisées dans le cadre des fonctionnalités pédagogiques de l'application.

Elles ne sont pas destinées à être vendues ou utilisées pour créer des profils publicitaires.

```
```

4. Génération des rapports

L'application peut permettre à l'élève de générer un rapport contenant ses résultats et informations pédagogiques.

La génération du rapport est effectuée sur l'appareil selon les fonctionnalités disponibles dans l'application.

Aucun envoi automatique :

La simple création d'un rapport ne signifie pas que celui-ci est envoyé automatiquement à l'enseignant ou à un serveur.

```
```

5. Partage par Email ou WhatsApp

L'utilisateur peut choisir de partager volontairement son rapport avec son enseignant ou une autre personne.

Le fonctionnement est le suivant :

  1. L'élève génère son rapport dans Edu Ezziymy.
  2. L'élève appuie sur le bouton Partager / Share.
  3. Android affiche les applications disponibles pour le partage.
  4. L'élève choisit par exemple WhatsApp ou Email.
  5. Le rapport est alors transmis par l'application sélectionnée au destinataire choisi par l'utilisateur.
Important :

Edu Ezziymy ne contrôle pas le traitement du rapport après sa transmission par WhatsApp, Email ou tout autre service de partage choisi par l'utilisateur.

Les données peuvent alors être traitées conformément à la politique de confidentialité du service utilisé.

```
```

6. Stockage local

Certaines informations peuvent être stockées localement sur l'appareil afin de permettre à l'application de fonctionner correctement, notamment hors connexion.

Ces informations peuvent inclure :

  • progression ;
  • résultats ;
  • préférences ;
  • contenus téléchargés ;
  • informations nécessaires au fonctionnement de l'application.
```
```

7. Téléchargement des fichiers

Edu Ezziymy peut permettre le téléchargement de documents pédagogiques afin de permettre leur consultation sur l'appareil.

Les fichiers téléchargés peuvent être conservés localement pour permettre leur utilisation ultérieure et éventuellement leur consultation hors connexion.

L'application ne demande pas un accès général aux fichiers personnels de l'appareil lorsque cet accès n'est pas nécessaire.

```
```

8. GitHub

Certains contenus pédagogiques et fichiers nécessaires au fonctionnement de l'application peuvent être hébergés sur GitHub.

L'application peut communiquer avec GitHub afin de télécharger ou mettre à jour ces contenus.

Ces contenus peuvent notamment comprendre :

  • documents pédagogiques ;
  • exercices ;
  • supports de cours ;
  • fichiers de configuration ;
  • mises à jour de contenu.
Protection des données scolaires :

Les données personnelles et les rapports scolaires des élèves ne sont pas destinés à être publiés dans les dépôts GitHub utilisés pour les contenus pédagogiques.

```
```

9. Publicité et Google AdMob

Edu Ezziymy peut utiliser Google AdMob afin d'afficher des annonces publicitaires dans certaines parties de l'application.

Dans le cadre de la diffusion des annonces, Google et ses partenaires publicitaires peuvent traiter certaines informations techniques relatives à l'appareil et à l'utilisation des services publicitaires.

Ces informations peuvent notamment être utilisées pour :

  • diffuser les annonces ;
  • mesurer les performances publicitaires ;
  • prévenir les activités frauduleuses ;
  • gérer les préférences publicitaires.
Données scolaires et publicité :

Les rapports, notes et résultats scolaires des élèves ne sont pas destinés à être utilisés pour personnaliser les annonces publicitaires.

```
```

10. Élèves mineurs

Edu Ezziymy est une application éducative pouvant être utilisée par des élèves mineurs.

Les données scolaires sont traitées uniquement dans le contexte pédagogique prévu par l'application.

Nous ne cherchons pas à collecter intentionnellement des données personnelles sensibles qui ne sont pas nécessaires aux fonctionnalités pédagogiques.

Responsabilité :

Les parents, responsables légaux et enseignants sont invités à veiller à ce que seules les informations nécessaires au suivi pédagogique soient utilisées dans les rapports.

```
```

11. Sécurité

Des mesures raisonnables sont mises en œuvre afin de protéger les informations traitées par l'application.

Toutefois, aucune méthode de stockage ou de transmission électronique ne peut garantir une sécurité absolue.

L'utilisateur doit également protéger son appareil et les applications utilisées pour partager ses rapports.

```
```

12. Conservation des données

Les données enregistrées localement peuvent rester sur l'appareil aussi longtemps qu'elles sont nécessaires au fonctionnement des fonctionnalités concernées ou jusqu'à leur suppression.

Lorsqu'un utilisateur partage volontairement un rapport par Email ou WhatsApp, une copie peut être conservée par le service utilisé pour le partage selon ses propres mécanismes.

Edu Ezziymy ne contrôle pas la durée de conservation des fichiers après leur transmission à un service tiers.

```
```

13. Suppression des données

L'utilisateur peut supprimer les informations locales lorsque les fonctionnalités correspondantes sont disponibles.

La désinstallation de l'application peut également supprimer les données stockées localement par l'application, sous réserve des mécanismes de sauvegarde Android.

Les rapports déjà envoyés par Email ou WhatsApp peuvent rester disponibles dans les comptes, appareils ou systèmes du destinataire et du service utilisé.

```
```

14. Services tiers

Certaines fonctionnalités de l'application peuvent utiliser des services externes.

  • Google AdMob : diffusion des annonces publicitaires.
  • GitHub : hébergement et téléchargement de certains contenus pédagogiques.
  • Email : partage volontaire des rapports par l'application de courrier électronique choisie par l'utilisateur.
  • WhatsApp : partage volontaire des rapports avec le destinataire choisi par l'utilisateur.

Les services tiers sont indépendants d'Edu Ezziymy et peuvent appliquer leurs propres conditions d'utilisation et politiques de confidentialité.

```

15. Droits des utilisateurs

Selon la législation applicable, les utilisateurs peuvent disposer de droits concernant leurs données personnelles, notamment :

  • demander l'accès aux données les concernant ;
  • demander la correction de données incorrectes ;
  • demander la suppression de certaines données ;
  • demander des informations sur l'utilisation de leurs données ;
  • exercer les autres droits prévus par la législation applicable.
