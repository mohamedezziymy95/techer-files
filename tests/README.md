# ملفات الاختبارات الجاهزة للنشر

انسخ **محتويات** هذا المجلد إلى المجلد `tests/` داخل مستودع:

`mohamedezziymy95/techer-files`

يقرأ التطبيق `tests/index.json` أولاً، ثم يحمل ملف الاختبار المحدد في الحقل `path`.

## تعديل تمرين دعم

داخل السؤال يمكن تعديل البنية التالية دون الحاجة إلى تحديث التطبيق:

```json
{
  "explanation": "شرح مركز يظهر قبل التمارين",
  "worked_example": "مثال محلول",
  "hint": "تلميح بعد الخطأ",
  "support_exercises": [
    {
      "id": "q1_support_1",
      "text": "نص تمرين الدعم",
      "options": ["اختيار 1", "اختيار 2", "اختيار 3", "اختيار 4"],
      "correct": 1,
      "explanation": "تصحيح وشرح الجواب",
      "image": "1BAC/physics/images/example.png"
    }
  ]
}
```

قيمة `correct` تبدأ من الصفر: `0` للاختيار الأول، و`1` للثاني، وهكذا.

يمكن نسخ الملف `_TEST_JSON_TEMPLATE.json` كنقطة بداية لإنشاء اختبار جديد، ثم تسجيل مساره داخل `index.json`.

يمكنك تعديل الملفات مباشرة داخل GitHub، وسيقرأ التطبيق التغييرات عند فتح قائمة الاختبارات من جديد.

إذا عدّلت النسخة الموجودة داخل مشروع Android في `app/src/main/assets/tests`، شغّل من جذر المشروع لمزامنتها مع هذا المجلد:

```bash
python3 tools/enrich_tests.py
```

لن يظهر أي اختبار للتلاميذ إلا إذا كان مسجلاً في `index.json` وكان `level` مطابقاً لأحد القيم:
`1AC`، `2AC`، `3AC`، `TCS`، `1BAC`، `2BAC`.
